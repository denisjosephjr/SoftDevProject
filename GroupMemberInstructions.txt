Clone the Repository Locally to work on the project.
(I recommend installing GitHub Desktop, its just easier to configure with VS Code)

Run the "SetUpDatabase.sql" script in DBeaver. You should be able to go to DBeaver
the click "File" -> "Open" -> Search for "SetUpDatabase.sql". Run the script and it 
will set up a database on your system with some test values.

Once that is done go to Main.java file in the src folder in the local repo. Then right
click it and press "Run Java" to run the file. (Run Code doesn't work, I learned the
hard way for like an hour).

You should see the employee names in the terminal (Nolan, Walter, Mark) after you 
enter all of your user inputs and most of the pain of the setup is done.

If you have problems, let me know. The setup is not really intuitive and sometimes 
a bit of a pain.
